# 托盘与开发运行

`AiLocalApi.Desktop.exe` 打开管理窗口；`--tray` 仅显示托盘。关闭窗口只隐藏，暂停不必要刷新；托盘可再次打开。退出命令使用显式关闭生命周期，依次停止接单、HTTP 服务、下载、调度与 Worker。锁屏不是退出信号，API 和任务继续运行；注销/会话结束由 Avalonia 的 ShutdownRequested 进入协调退出。

每个 Windows 用户的同一程序副本只允许一个实例：使用当前用户 SID 与程序根目录标识命名的 Local mutex + CurrentUserOnly 管道；再次打开同一副本唤醒已有窗口。不同副本可独立运行，但不能共用 API 端口。`AiLocalApi.Desktop.exe --exit` 向同一副本发送退出请求，供本地验证使用，不额外创建后台宿主。

端口默认 17840，可在设置页点击“应用端口并重启 API”，仅重建 HTTP 监听、保留应用服务与异步队列。新端口绑定失败保留原监听；同步 HTTP 连接可能中断。`AILOCAL_PORT` 仅覆盖初次启动，之后界面的显式重启使用所填端口。端口占用时托盘和窗口给出错误，不假报 API 可用。`/health` 可单独验证服务可达性。

登录启动默认关闭。开启后注册当前用户、当前副本专属的 Run 项，不需要管理员权限。开发运行使用当前 apphost 的完整路径加 `--tray`，移动/删除构建目录会导致入口失效，应在新路径重新保存开关。安装版和绿色版使用发行根目录的稳定入口 `AiLocalApi.exe --tray`；绿色版移动后修复自己已启用的启动项，安装版卸载仅清理自己的启动项。应用不安装 Windows Service。发行布局、数据选择与自动更新见 [发行说明](RELEASE.md)。
