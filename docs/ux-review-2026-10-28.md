## 方案选择

保留任务、模型、设置的现有工作路径，新增 API 密钥页。相较于把所有选项继续堆在设置页，独立页面可以容纳密钥列表与一次性展示区域，减少误操作。设置页按 API 服务、推理、下载和常规选项分组；按钮直接说明动作，反馈留在相应区域。

推理测试使用独立 Worker 实际加载一个已校验的本地模型，测试结束释放资源；下载测试仅获取模型文件头，不能代替完整下载的摘要校验。端口切换先绑定新端口，成功后关闭旧监听，应用服务及队列保持存活。

- Windows Sandbox（独立 VM、禁用 vGPU、自包含 .NET、共享程序目录只读）通过：七格式、44 秒跨块时间戳、排队/运行取消、重试、Worker 崩溃恢复、损坏输入隔离、四语指定语言/自动检测、实际后端与源探测。

### 音频质量边界

使用 Google FLEURS 固定版本的每语言一个 dev 样本，许可证、参考文本及 SHA-256 见 `scripts/multilingual-fixtures.json`。以 tiny / CPU 运行；以下为去标点、空白并执行 NFKC 后的字符错误率，数字表述、繁简体、缩写差异仍会计为错误，不能代表完整语言质量：

| 语言 | 时长 | 指定语言 CER | 自动检测 CER |
| --- | --- | --- | --- |
| 中文 | 18.38 秒 | 6.82% | 6.82% |
| 日语 | 11.10 秒 | 39.13% | 39.13% |
| 英语 | 6.54 秒 | 1.56% | 1.56% |
| 韩语 | 10.56 秒 | 20.00% | 20.00% |

八次均检测/返回正确语言，具有对应文字体系、非空词/分段及有效时间边界。日语、韩语存在明显识别错误；通过表示流程与数据结构可用，不表示识别准确率达标。

### 兼容与可恢复性

API 访问策略独立于普通设置；旧单密钥迁移后保持要求认证，未配置密钥时保持允许匿名。新密钥只持久化摘要；旧数据库迁移备份可能含历史明文。修改端口先绑定新监听，失败不影响旧服务；重启最多等待同步连接 5 秒，随后旧同步连接可能断开并取消，异步任务继续。
