# 数据、生命周期与恢复

程序目录不保存业务数据。默认数据目录为 `%LOCALAPPDATA%\AiLocalApi`，启动前设置 `AILOCAL_DATA` 可选绝对路径（中文、空格、非系统盘均按完整路径处理）；`state.db` 保存配置、模型元数据和任务，`jobs/<随机ID>` 保存上传/解码临时文件，`logs` 保存按日期的诊断日志。程序工作目录不参与路径解析。

模型目录由用户先选择，可与数据目录分离；切换目录只改变之后的下载位置，不隐式搬移已安装模型。存在在途任务、驻留模型或下载时拒绝变更。需要搬移时先卸载、结束任务，再选择新目录并导入模型；导入仅接受支持目录中 SHA-256 和大小匹配的文件。

SQLite schema 3 使用事务迁移，包含任务顺序与过期清理索引、独立密钥表与访问策略；升级前以 SQLite Backup API 生成 `.bak`，迁移失败不提交事务。版本高于支持范围时拒绝写入。二进制回退不会自动恢复旧数据库；应保留备份并用兼容版本打开。权限或数据库错误在启动窗口显示。

任务状态持久化先于调度通知。Channels 仅唤醒串行调度器。领取、取消、重试、成功提交在同一存储锁内转换；迟到结果不能覆盖已取消状态。宿主重启恢复 running，最多累计自动尝试两次；Worker 断连也最多尝试两次，显式重试才重置计数。正常退出停止接单，取消正在执行的计算并保存为 queued，协调 Worker 退出。推理不承诺崩溃时恰好计算一次。

保留期默认 7 天，从终态更新时间计算。每分钟至多清理 100 个过期任务，删除其上传和结果、保留 expired 元数据；运行中、排队和正在回收的任务不清理。已读取的结果为内存快照，不受后续清理影响。宿主重启清理没有数据库记录的随机任务目录。下载的 `.partial` 可继续下载，校验损坏文件重命名为 `.invalid-*`，保留供诊断；用户可在模型目录中自行确认后删除。应用不会后台删除模型。

空闲 TTL 从最后一个任务释放模型后计算；保持加载会禁用 TTL，手动卸载在忙时返回冲突。卸载向 Worker 发送退出请求，让原生上下文先释放；超过 3 秒才回收子进程。取消通过当前用户命名管道发送取消请求，原生代码不响应时有 3 秒终止后备。父进程被强制结束时，Worker 监视父进程并退出。

默认限制：上传 512 MiB、单个解码音频 2 小时、临时空间 2 GiB（接收新输入前为单个解码缓冲预留空间）、排队 100 项、执行时间 2 小时。长音频采用 30 秒 float PCM 缓冲，整段解码保存在受时长限制的临时文件中。日志只记录诊断码和任务 ID，不记录完整音频、提示或转写内容。

API 密钥表仅保存 SHA-256 摘要、名称、短前缀、启用状态和创建时间。随机密钥使用 32 字节密码学安全随机数；自定义值需 16–256 个无空白 ASCII 字符。旧 Settings.ApiKey 只用于迁移，迁移后清空；有旧密钥时禁用匿名访问，无旧密钥时保持允许。升级前备份可能保留旧版明文密钥，需要按原有敏感数据管理；新数据库不保存完整密钥。访问策略独立于普通设置，保存推理配置不会覆盖密钥变更。
